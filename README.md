# RPC-сервер и клиент на Python с тестированием на основе модели

Учебный проект: реализация RPC-сервера и клиента на чистом Python
(без сторонних RPC-фреймворков), покрытие функционала model-based
тестами на базе `hypothesis`.

---

## Содержание

Проект состоит из трёх слоёв:

1. **Слой данных (`DataLayer`)** — in-memory хранилище для трёх
   сущностей: клиентов (`client`), задач (`task`) и ответов
   (`response`). create, read, delete - операции плюс специальный запрос
   `query_right_join`.
2. **REPL (`Repl`)** — обёртка над `DataLayer`, которая парсит
   аргументы, валидирует их количество и возвращает
   человекочитаемые строки. Используется и локально, и как
   backend RPC-сервера.
3. **RPC-транспорт (`RPCBase`, `RPCServer`, `RPCClient`)** —
   бинарный протокол поверх TCP-сокетов: 2 байта `opcode`,
   4 (или 5) байта длины, тело в XML.

Клиент шлёт opcode + сериализованные аргументы, сервер
диспетчеризует их по таблице `ops`, выполняет соответствующий
метод REPL и возвращает сериализованный результат.

## Запуск

Запускать из корня проекта: `cource_work`

Запуск сервера выполняется командой `make server`

Запуск клиента выполняется командой `make client`
